## 🙋 About Me

Hey, I'm **Neel** — a CS student at Toronto Metropolitan University passionate about building things that matter, from full-stack apps to data pipelines to quant finance tools.

- 🏢 **Interned at** Quality Cheese Inc. & Meghal Road Equipment — built automation tools and data dashboards used in production
- 📊 **Currently building** data science projects with Python, pandas, scikit-learn, and Power BI on real-world housing and startup datasets
- 📱 **Stack I love** — Java, Python, JavaScript, React Native, SQL for end-to-end mobile and web projects
- 📈 **Exploring** quantitative finance: risk modelling, backtesting strategies, and portfolio optimization with Python/SQL
- ☁️ **Learning** Azure, AWS, scalable backend design, and production-level testing across the SDLC
- 🤝 **Looking to collaborate** on fintech, analytics, or data pipeline projects — especially anything investment-related
- 🎯 **Targeting** internship roles in Software Development, Data/Analytics, or Quality Engineering at TD, RBC, and big tech
